# Lisens for dataene

MIT-lisensen i `LICENSE` gjelder koden i dette repoet.

Dataene i `data/`, `indeks.json`, `manifest.json` og `endringer/` er avledet fra [Lovdata](https://lovdata.no) og følger [Norsk lisens for offentlige data (NLOD 2.0)](https://data.norge.no/nlod/no/2.0). Den som bruker dataene videre, må oppgi Lovdata som kilde og vise til NLOD 2.0.

Repoet er ikke tilknyttet Lovdata. Den offisielle teksten finnes på lovdata.no.
